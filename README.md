## 🚀 Featured Project

### Pub-Xel

**Pub-Xel** is an open-source platform built on a simple idea:

> *Medical knowledge shouldn't remain fragmented across thousands of papers.*

By organizing, synthesizing, and connecting biomedical literature, Pub-Xel aims to make scientific evidence more accessible, reproducible, and clinically useful for researchers and physicians.
